# Chatbot Web Application 

A simple interactive chatbot web application built with **React and Vite**. This project was created to practice React fundamentals, component-based development, state management, event handling, and building an interactive user interface.

## Features

* 💬 Send messages and receive chatbot responses
* ⚛️ Component-based React architecture
* 🔄 Dynamic chat updates using React state
* ⌨️ Press **Enter** to send a message
* ❌ Press **Escape** to clear the input
* 📜 Automatically scrolls to the latest message
* 👤 Separate user and chatbot message profiles
* 📱 Clean and responsive chat interface

## Technologies Used

* **React**
* **JavaScript**
* **Vite**
* **CSS**
* **React Hooks** (`useState`, `useEffect`, `useRef`)
* **Supersimpledev Chatbot Library**
